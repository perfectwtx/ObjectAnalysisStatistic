# 问题中心

Issue Center 是数据质量问题的统一入口。

## 问题来源

问题主要来自质量规则和分析过程，例如：

- 必填 / 完整性检查
- 类型检查
- 枚举检查
- 范围检查
- Pattern 检查
- 唯一性检查
- 数据集期望检查
- Schema 变化
- 分布或异常检测

## 问题结构

标准问题至少包含：

- Job
- Field
- Check Type
- Issue Count
- Message

因此可以按任务、字段和检查类型聚合问题。

## 排查路径

推荐从整体到局部：

```text
质量分
  ↓
质量维度
  ↓
字段
  ↓
检查类型
  ↓
问题数量 / 消息 / 样本
```

## 与原始分析结果的关系

Issue Center 保存可查询的标准化问题；原始分析结果仍保留在分析结果中，以避免为了满足每一种查询场景而不断修改核心结果模型。
