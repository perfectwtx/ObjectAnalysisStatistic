# 安全

ObjectAnalyzer 可能处理业务原始数据，因此安全边界优先于展示便利性。

## 原始数据

分析过程可以读取原始值，但原始业务数据不应因为历史、日志或告警而被无期限持久化。

## PII

PII 识别和脱敏属于统一的出站边界能力。API、报告、预览等对外输出应使用统一策略。

## 日志

日志中不得记录密码、Token、数据库凭据、Webhook 密钥或不必要的原始敏感数据。

## Webhook

Webhook 地址和相关认证信息属于敏感配置。生产环境建议使用 HTTPS，并限制接收端权限和网络访问范围。

## 历史数据

平台历史主要保存任务、质量指标、字段快照和标准化问题。持久化内容应遵循最小化原则。

更完整的漏洞披露和安全政策见仓库根目录 `SECURITY.md`。
