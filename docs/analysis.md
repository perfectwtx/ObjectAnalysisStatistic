# 分析引擎

分析引擎以 `AnalysisPipeline` 为统一入口，将数据源处理和分析计算组织成一条可复用的执行路径。

## 处理流程

```text
输入
 ↓
格式识别 / 解析
 ↓
JSONPath 投影（可选）
 ↓
字段选择
 ↓
值转换
 ↓
过滤
 ↓
采样
 ↓
字段统计与深度分析
 ↓
质量检查 / Schema
 ↓
AnalysisResult
```

## 字段统计

字段统计覆盖：

- 出现次数与覆盖率
- null 数量
- 类型分布
- 唯一值数量
- 高频值
- 字符串长度
- 数值统计
- 时间范围与时间分布
- 异常值

针对大数据量场景，部分统计使用受控内存结构和近似算法，避免简单地把全部唯一值永久保存在内存中。

## Pipeline Runtime Context

运行时状态通过 `AnalysisRunContext` 显式传递，例如：

- 内存预算
- 续跑位置
- 进度
- 预览数据
- 执行观察器

这样可以保持分析核心与具体宿主解耦。

## 分析结果

`AnalysisResult` 是核心分析输出。平台层不会把每一种查询需求都强行加入核心结果模型，而是从结果生成质量快照、字段快照和标准化问题。
