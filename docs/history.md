# 历史与趋势

每次成功分析都可以形成质量快照，用于回答“这次比上次好还是坏”。

## 数据集级快照

`QualitySnapshot` 保存：

- 数据源
- 分析时间
- 对象数量
- 字段数量
- 问题数量
- 五个质量维度
- 综合质量分

## 字段级快照

`FieldQualitySnapshot` 保存字段在某次分析中的质量指标，用于字段趋势和质量定位。

## 趋势

趋势查询按数据源和时间排序，比较连续分析之间的质量变化。

典型场景：

- 质量持续下降
- 某次发布后质量突降
- 某字段 null 率逐步升高
- 异常值比例突然增加

## 当前存储

当前历史实现使用 SQLite。存储接口与查询接口独立于 Web 页面，因此未来切换 PostgreSQL 等数据库不需要修改上层业务模型。
