# 路线图

路线图描述产品方向，不描述已经完成的历史开发批次。

## 当前状态

ObjectAnalyzer 已从单次对象统计工具扩展为数据质量分析平台。

当前核心链路：

```text
数据源 → 分析任务 → 分析引擎 → 质量结果 → 历史 → Dashboard → 告警
```

已完成的核心能力包括：

- 数据质量评分与质量问题识别
- Quality Baseline 与质量趋势
- Schema Diff 与影响分析
- 对象关系分析
- Data Lineage 数据血缘
- Impact Analysis 影响分析
- 问题责任定位
- 修复记录与自动修复验证
- Alert / Webhook
- CLI / API / Web 能力

## 下一阶段

### 1. 数据质量增强

- 更丰富的质量规则
- 更精确的质量评分
- 字段级质量诊断

### 2. 可观测性

- 更完整的质量趋势
- 数据分布漂移增强
- 分析任务运行指标
- 历史对比增强

### 3. 数据关系增强

- 字段相关性增强
- 关系变化检测
- 更丰富的血缘可视化
- 更精细的影响传播模型

### 4. 产品化

- 完善测试覆盖
- API / Web 能力持续对齐
- 文档与示例完善
- Docker / 发布流程持续完善

## 原则

每一个新能力都应优先形成稳定的数据模型和可复用服务，再提供 CLI、API、Web 展示，避免功能只存在于某一个宿主中。
