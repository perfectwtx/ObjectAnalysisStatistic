# 路线图

路线图描述产品方向，不描述已经完成的历史开发批次。

## 当前方向

ObjectAnalyzer 已从单次对象统计工具扩展为数据质量分析平台。

当前核心链路：

```text
数据源 → 分析任务 → 分析引擎 → 质量结果 → 历史 → Dashboard → 告警
```

## 下一阶段

### 1. 数据质量增强

- 更丰富的质量规则
- 更精确的质量评分
- 字段级质量诊断
- 质量基线与阈值管理

### 2. 可观测性

- 更完整的质量趋势
- 数据分布漂移
- 分析任务运行指标
- 历史对比

### 3. 数据关系

- 字段相关性
- 对象关系分析
- Schema Impact
- 关系变化检测
- 数据血缘

### 4. 数据治理

- 数据血缘
- 影响分析
- 质量问题责任定位
- 修复闭环

### 5. 产品化收尾

- 完整测试覆盖
- API / Web 能力对齐
- 文档与示例完善
- Docker / 发布流程检查

## 原则

每一个新能力都应优先形成稳定的数据模型和可复用服务，再提供 CLI、API、Web 展示，避免功能只存在于某一个宿主中。
