# 配置与参数

配置分为四层：

```text
数据源
  ↓
解析配置
  ↓
分析配置
  ↓
质量规则
```

## 输入

支持 JSON、JSONL、CSV、Excel、XML、YAML，以及压缩输入和数据库数据源。

## 分析配置

常见分析控制项包括：

- 字段选择
- JSONPath 投影
- 过滤表达式
- 采样
- 唯一值跟踪上限
- 预览数量
- 内存预算
- PII 策略

## 规则

规则用于表达业务约束，例如：

- 必填
- 唯一
- null 率
- 枚举
- 范围
- Pattern
- 默认值
- 主导类型
- 数据集期望

规则文件应优先使用项目提供的示例模板作为起点。

## 参数事实来源

CLI 参数、规则键和运行时配置都可能随着版本演进调整。使用 CLI 时，以 `--help` 和当前代码中的选项定义为最终事实来源。
