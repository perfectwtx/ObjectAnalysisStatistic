# API

API 项目位于 `src/ObjectAnalyzer.Api`，用于向 React 或其他业务系统提供分析能力。

## 定位

API 是 Core 分析能力和前端 / 外部系统之间的 HTTP 适配层。业务系统不需要直接引用分析引擎内部实现。

## 主要能力

- 提交分析请求
- 获取分析结果
- 获取字段分析信息
- 获取数据质量信息
- 获取问题信息
- 获取历史分析结果

## 接入原则

建议调用方把数据源、分析配置和规则作为请求输入，把分析结果作为业务侧数据质量判断的依据。

涉及 PII 的数据不应直接进入日志。对外响应和导出应遵循统一的数据脱敏策略。

## API 文档

启动 API 后，通过项目提供的 OpenAPI / Scalar 页面查看当前实际接口、请求模型和响应模型。

接口文档以运行中的 OpenAPI 定义为准，本文只描述 API 的职责，不复制容易过期的接口清单。
